# Sparkle Updates

JustAboutTime uses Sparkle 2.8.1 for macOS update detection, download, signature validation, and installation.

## App Configuration

- `UpdateManager` owns `SPUStandardUpdaterController` and starts Sparkle during app initialization.
- `Info.plist` sets `SUFeedURL` to `https://github.com/moophis/JustAboutTime/releases/latest/download/appcast.xml`.
- `Info.plist` reads `SUPublicEDKey` from the `SPARKLE_PUBLIC_ED_KEY` build setting.
- The About window exposes manual update checks plus persisted automatic check/download toggles.

## Release Requirements

`SPARKLE_PUBLIC_ED_KEY` is set to the Ed25519 public key generated by Sparkle's `generate_keys --account JustAboutTime` tool. The matching private key is stored in the user's login keychain under the `JustAboutTime` account. Do not commit or export the private key.

For each release:

1. Build, sign, and notarize `JustAboutTime.app`.
2. Zip the app archive for Sparkle distribution.
3. Run Sparkle's `generate_appcast` with the private Ed25519 key to update `appcast.xml`.
4. Upload the zip and `appcast.xml` to the GitHub Release.
5. Confirm the appcast item includes the Sparkle signature and version metadata.

Sparkle handles version comparison, authenticated download, validation, installation, and relaunch prompts. The app should not reintroduce custom DMG mounting or bundle replacement logic.
